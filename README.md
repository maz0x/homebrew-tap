# maz0x/homebrew-tap

Homebrew tap for [Burndown](https://github.com/maz0x/burndown), a macOS menu bar
monitor for Claude session and weekly usage limits.

```bash
brew install --cask maz0x/tap/burndown
```

Releases are ad-hoc signed for now, so if macOS refuses to open the app, add
`--no-quarantine` to that command, or right-click the app and choose Open once.
